# 분산 구동의 주소 지정 방식

여러 구동 요소 중 원하는 것만 골라 구동하는 방법이다.

| 방식 | 뜻 | 예 |
|---|---|---|
| direct addressing | 요소마다 전용 회로·배선이 있다 | [Johnson 2023](../papers/johnson2023.md): 셀별 하프브리지 (p.3 Fig. 2c) |
| 독립 채널 | 리본 하나가 채널 하나다. 막 전체는 리본들의 결합으로 변형된다 | [Ni 2022](../papers/ni2022.md): 4-by-4 = 8채널 (p.3) |
| networked domain | 전극 수보다 구동 요소가 많다. 전극 전압 패턴으로 분포를 만든다 | [Park 2025](../papers/park2025.md): 전극 64개 → 저항체 308개 (p.3) |
| 설계 고정 + 압력 조합 | 요소 배치는 고정되어 있고, 입력 조합으로 모드를 고른다 | [Zhang 2023](../papers/zhang2023.md): 7모드 (p.3 Fig. 3a) |

- Park 2025는 Johnson 2023을 "direct addressing"으로, Ni 2022를 주변 전극 자극형 networked domain으로 인용한다 (Park 2025 p.1–2).
- [추론] Ni 2022는 채널 단위로 보면 직접 주소 지정에 가깝다. 표의 분류는 이 위키가 정리한 것이다.
- [추론] 요소 수를 늘릴 때 회로 수가 어떻게 늘어나는지가 방식 간의 핵심 차이다.

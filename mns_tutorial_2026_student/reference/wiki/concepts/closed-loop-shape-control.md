# 폐루프 형상 제어

측정한 상태를 되먹여 목표 형상과의 오차를 줄이는 제어다. **무엇을 측정해 루프를 닫는가**가 논문마다 다르다.

| 논문 | 루프를 닫는 변수 | 대역폭·속도 | 원문 위치 |
|---|---|---|---|
| [Park 2025](../papers/park2025.md) | 온도 (RNI) | 약 0.1 Hz | p.4 Fig. 4c–d |
| [Johnson 2023](../papers/johnson2023.md) | 셀 높이(변형) | 20 Hz | p.5–6 Fig. 4b |
| [Ni 2022](../papers/ni2022.md) | 없음(라이브러리 검색, 개루프) | 응답 약 300 ms | p.3–5 |
| [Zhang 2023](../papers/zhang2023.md) | 없음(개루프 시퀀스) | needs_review | p.5–6 |
| [Yan 2023](../papers/yan2023.md) | 논리 게이트(이진 판단) | 게이트 지연 약 1.5 s | p.3–4 |

- [추론] 대역폭 수치는 측정 조건과 대상 변수가 서로 달라 직접 비교할 수 없다. 크기 수준만 참고한다.

# 프로젝트 목표

대상 논문 "Field-programmable robotic folding sheet"(Park et al., Nature Communications 2025)를 관련 논문과 비교해, 이 논문이 남긴 공백을 찾고 검증 가능한 연구 질문(RQ)을 도출한다.

# 작업 흐름과 폴더

1. 논문 수집: `papers/`. 작업 전에 `papers/README.md`를 읽고 따른다.
2. 논문 정리: `wiki/papers/`. 논문 한 편당 한 페이지를 만든다. 작업 전에 `wiki/README.md`를 읽고 따른다.
3. 비교: `wiki/matrix.md`. 여러 논문을 같은 비교 축으로 정리한다.
4. RQ 도출: `wiki/rq.md`. 비교표에서 찾은 공백을 RQ 후보로 바꾼다.
5. 대상 논문 이해: `explainer/`. 위키를 배경지식으로 대상 논문 설명 페이지를 만든다. 작업 전에 `explainer/README.md`를 읽고 따른다.

# 연구 키워드

Field-programmable robotics, Shape-morphing robotics, Programmable folding, Distributed electrothermal actuation, Spatially addressable actuation, Self-sensing actuators, Resistive Network Imaging (RNI), Closed-loop shape control

# 검증 규칙 (모든 작업에 적용)

- 원문에 적힌 내용과 나의 추론을 구분한다. 추론에는 `[추론]`을 붙인다.
- 주장과 수치에는 원문 위치(p. / Fig. / Table)를 함께 적는다.
- 확인하지 못한 내용은 채우지 않고 `needs_review`로 남긴다. 제목·DOI·수치를 지어내지 않는다.
- 원문을 확보하지 못한 논문은 요약하지 않는다.

# RQ 형식

RQ에는 조건, 비교 대상, 측정값, 판정 기준이 모두 있어야 한다. 근거가 된 공백과 원문 위치를 함께 적는다. 사람이 승인하기 전까지 RQ의 상태는 `후보`다.

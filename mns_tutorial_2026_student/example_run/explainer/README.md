# explainer/ — 대상 논문 이해 페이지

## 역할
위키에 쌓인 배경지식(비교 논문, 개념)을 써서, 대상 논문을 처음 읽는 사람이 이해할 수 있는 설명 페이지(HTML)를 만든다.

## 입력 → 출력
- 입력: `wiki/papers/`, `wiki/concepts/`, `wiki/matrix.md`, `papers/pdf/`, `papers/collection_status.csv`(라이선스)
- 출력: `explainer/park2025.html`(한 페이지), `explainer/figures/`(그림 파일). 완성되면 아티팩트로 게시한다.

## 작업 순서
1. 대상 논문의 핵심 주장 3–5개를 위키 페이지에서 고른다(원문 위치 포함).
2. 주장마다 이해에 필요한 배경 개념을 `wiki/concepts/`에서 찾는다.
3. 주장마다 비교 논문(`wiki/matrix.md`) 가운데 대비가 가장 잘 되는 연구를 골라, 그 논문의 그림으로 "다른 연구는 이렇게 했다"를 보여 준다.
4. 대상 논문의 그림과 나란히 놓고, 무엇이 새로운지 한 문장으로 적는다.
5. HTML 한 페이지로 만들고 아티팩트로 게시한다.

## 지킬 것
- 그림마다 출처(논문, Fig. 번호)와 라이선스를 적는다. 라이선스는 `collection_status.csv`의 `license` 열을 따른다.
- `cc-by-nc-nd` 그림(대상 논문)은 자르거나 고치지 않고 그림 전체를 쓴다. `cc-by` 그림은 패널을 잘라 써도 되고, 그때는 "일부 발췌"라고 적는다.
- 설명 문장에는 원문 위치를 달고, 해석은 [추론]으로 표시한다.
- 위키에 없는 내용은 원문에서 확인한 뒤에만 쓴다. 확인하지 못하면 `needs_review`로 둔다.

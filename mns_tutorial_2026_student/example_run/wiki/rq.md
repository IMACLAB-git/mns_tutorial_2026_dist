- **`[추론]`:** 원문에 없는 해석이다.
- **(제안):** 원문 값이 아니라 실험 설계를 위해 새로 정한 값이다. 승인할 때 조정할 수 있다.
- **상태:** 모든 RQ는 사람이 승인하기 전까지 `후보`다.

## RQ 후보

### RQ1. 외부 하중에서 형상 되먹임이 곡률 오차를 줄이는가
**상태: 후보**

| 항목 | 내용 |
|---|---|
| 질문 | Park형 접힘 시트에 외부 하중이 걸릴 때, 곡률을 직접 되먹이는 제어가 Park의 온도 PI 제어보다 정상상태 곡률 오차를 줄이는가? |
| 근거 공백 | G1: Park p. 4; Fig. 3a; p. 6. Johnson p. 5–6; Fig. 4a, c |
| 조건 | • 시트: Park 방식(7 × 7 블록, 전극 64개, 저항 308개, PI/PDMS/SU-8; Park p. 3)<br>• 접힘: Fig. 2c와 같은 단일 선 접힘 구성 (Park p. 3; Fig. 2c)<br>• 목표 평균 곡률 κ_ref: 0.5, 1.0, 1.35 cm⁻¹ (제안. 1.35는 Park의 위치별 평균값; Park p. 3; Fig. 2e)<br>• 하중: 접힘선 바깥 자유단에 정적 하중, 시트 자중의 0, 1, 2, 4배 (제안. 상한 4배는 Park의 최대 payload-to-weight; Park p. 5; Fig. 5c)<br>• 반복: 조건마다 5회 (제안) |
| 비교 대상 | • (A) **기준:** Park의 온도 PI 폐루프 (P = 0.4, I = 0.009; Park p. 9)<br>• (B) **곡률 되먹임 cascade:** 외부 카메라로 잰 κ_avg를 외부 루프로 되먹여 (A)의 온도 목표를 조정한다. Johnson의 형상–내부 루프 cascade 구조를 참고했다 (Johnson p. 5; Fig. 4a)<br>• (B)는 이상적인 형상 센서를 가정한 **상한선**이다. [추론] intrinsic shape sensing을 개발할 가치가 있는지 먼저 판단하려는 설계다 |
| 측정값 | • 정상상태 곡률 오차 e_κ = \|κ_avg − κ_ref\| (cm⁻¹). 외부 카메라 윤곽 추적(Park Fig. 2c 방식)<br>• 정착시간 (s)<br>• 최고 온도 (°C). 작동 상한 170 °C 대비 (Park p. 3) |
| 판정 기준 | • **"형상 되먹임 필요"(G1 확인):** 하중이 자중 2배 이상일 때 (A)의 e_κ 평균이 0.20 cm⁻¹를 넘고, (B)가 (A) 대비 e_κ를 50 % 이상 줄인다. 0.20 cm⁻¹는 Park이 보고한 위치별 곡률 편차(1.35 ± 0.20 cm⁻¹; Park p. 3; Fig. 2e)이고, 50 %는 (제안)이다.<br>• **"온도 되먹임으로 충분":** 모든 하중에서 (A)의 e_κ가 0.20 cm⁻¹ 이내다.<br>• 두 경우 모두 아니면 **"조건부"**로 판정하고, e_κ가 0.20 cm⁻¹를 넘기 시작하는 하중을 보고한다.<br>• (B)가 170 °C에 걸려 목표에 못 가면 **"가열 한계"**로 따로 기록한다 |

### RQ2. 강제 대류 냉각이 폐루프 대역폭을 얼마나, 어떤 전력 비용으로 올리는가

## RQ로 만들지 않은 공백 후보
공백 표에는 넣지 않았다. 근거가 추론에 머물거나 먼저 확인할 사실이 있다.
- **무전력 형상 유지:** Park은 접힘을 유지하는 데 필요한 전력을 명시하지 않았다. 수동 냉각으로 복귀하므로 지속 가열이 필요하다는 것은 [추론]이다 (Park p. 2–3). Yan의 쌍안정(Yan p. 3–4)과 Ni의 갈륨 상변화 고정(Ni p. 5)이 대비 사례다. 접힘 유지 전력을 먼저 측정해야 공백으로 확정할 수 있다 ([shape-retention.md](concepts/shape-retention.md)).
- **RNI로 접촉·하중 감지:** Johnson은 같은 셀 배열로 힘을 추정한다 (Johnson p. 5; Fig. 3e). Park의 RNI는 온도만 추정한다 (Park p. 4). 저항 네트워크 신호가 접촉에 반응하는지부터 원문에 근거가 없다.

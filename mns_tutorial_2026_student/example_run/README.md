# example_run/ — 캡처 실행 결과

`GUIDE.md`의 화면을 찍을 때(2026-09-29) Claude Code가 `workspace/`에서 실제로 만든 파일이다. 캡처 화면과 대조해 볼 수 있도록 남겼다.

- PDF(`papers/pdf/`)는 빼고 두었다. 필요하면 `backup_pdf/`를 쓴다.
- `explainer/`는 6단계(추가 실습) 실행 결과다. `park2025.html`을 브라우저로 열면 `figures/`의 그림 11장과 함께 보인다. `README.md`는 에이전트가 따른 규칙 문서다.
- `CLAUDE.md`는 6단계용 줄(5번)을 더한 상태다.
- **사람이 원문과 대조하지 않은 상태**다. 논문 페이지의 `status`는 `summarized`이고, RQ의 상태는 `후보`다. 설명 페이지의 개념도처럼 에이전트가 직접 그린 그림도 원문과 대조하지 않았다.
- 강사가 정리한 짧은 완성본은 `reference/`에 있다. 두 폴더의 내용이 서로 다른 것은 실행할 때마다 결과가 달라지기 때문이다.

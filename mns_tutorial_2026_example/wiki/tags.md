# 태그 어휘

논문 페이지의 `tags:`에는 이 목록에 있는 태그만 쓴다. 주제 허브(`hubs/topics/`)는 이 태그로 만든다.

- 태그를 더하거나 바꾸는 것은 사람이 정한다. 에이전트는 어휘에 없는 태그를 논문 페이지에 넣지 않고, 필요하면 사람에게 제안한다.
- 형식: 한 줄에 하나. 소문자와 하이픈으로 쓰고 뜻을 한 줄 붙인다.
- 이 어휘는 `CLAUDE.md`의 "연구 키워드" 8개를 옮긴 것이다. 논문마다 붙인 태그의 근거는 `matrix.md`와 개념 페이지에 있다.

- `field-programmable-robotics`: 배치 뒤 현장에서 형상 변형의 구성(접힘의 영역·방향·정도)을 다시 정한다
- `shape-morphing-robotics`: 형상을 바꾸는 로봇·시트·표면
- `programmable-folding`: 접힘의 위치·방향·정도를 제작 뒤에 프로그래밍한다
- `distributed-electrothermal-actuation`: 면에 분포한 저항 발열(Joule)과 이중층 열팽창 차이로 국소 접힘을 만든다
- `spatially-addressable-actuation`: 분산된 구동 요소를 공간적으로 골라 구동한다(direct / matrix / networked domain)
- `self-sensing-actuators`: 외부 계측 장비 없이 장치가 자기 상태를 잰다(intrinsic 또는 embedded)
- `resistive-network-imaging`: 저항 네트워크에 전류를 주입하고 전압을 재 역문제로 저항(온도) 분포를 재구성한다
- `closed-loop-shape-control`: 상태를 측정해 구동 입력을 되먹인다. 되먹임 변수(온도인지 형상인지)를 구분한다

# manuscript/ — 원고 = 연구 설계도

## 역할
가설의 논리 연결을 원고 형태로 먼저 세우고, 판정이 나는 즉시 결과를 채운다.

## 입력 → 출력
- 입력: `bigpicture.md`, `hypotheses/`, `experiments/*/result.md`, `wiki/`(서론 근거와 글쓰기 패턴)
- 출력: `draft.md`, `figures/`

## 작업 순서
1. 큰 그림이 정해지면 `draft.md`의 Introduction 논리 사슬과 Results 골격을 먼저 쓴다.
2. Results에는 가설마다 절을 하나 두고, 태그를 단다: `[대기]` / `[채택 E03]` / `[기각 E02]`.
3. `[대기]` 절에는 예상 결과와 기각 기준만 적는다.
4. Methods에는 실험 전 프로토콜 요약을 `[계획]`으로 적는다.
5. 판정이 나면 해당 절을 결과 문장, 그림, 실험 링크로 바꾼다.
6. 가설이 기각되면 그 절을 지우지 않고 Discussion으로 옮긴 뒤, Introduction의 논리 사슬을 다시 잇는다.
7. 문장을 다듬을 때 `wiki/writing.md`와 논문 페이지의 글쓰기 노트를 참고한다.

## 지킬 것
- Results의 문장은 [실험] 근거만 쓴다. [시뮬]은 Methods나 Supplementary의 보조 근거로만 쓴다.
- 모든 문장에 출처를 단다: 문헌은 위키 논문 페이지와 원문 위치, 결과는 실험 ID.
- `[대기]` 절과 `[계획]` 절을 결과처럼 쓰지 않는다.
- 신규성 서술은 `bigpicture.md`의 "현재 search 범위" 안에서만 한다.
- 주장 문장의 확정은 사람이 한다. 에이전트가 쓴 문장은 확정 전까지 초안이다.

# 연구 원칙

1. **Search and search.** 문헌 탐색은 라운드로 반복한다. 라운드마다 참고문헌·인용 논문·키워드로 찾고, 새 논문을 넣어도 비교표와 공백 판정이 바뀌지 않으면 그 라운드를 닫는다. 신규성은 "현재 수집 범위 안에서"로 말한다.
2. **큰 그림 → 최소 가설.** 가설은 가추로 세운다(관찰 → 가장 그럴듯한 설명 → 대안 설명). 한 번의 실험으로 판정할 수 있는 크기로 쪼개 가설-검증-기각을 빠르게 돌린다.
3. **기각 기준은 검증 전에 적는다.** 결과를 본 뒤 가설이나 기준을 고치지 않는다. 고쳐야 하면 새 가설로 만든다.
4. **기각도 결과다.** 기각된 가설과 실험은 지우지 않고 이유와 함께 남긴다.
5. **원고가 설계도다.** 가설의 논리 연결은 `manuscript/draft.md`에 먼저 있다. 판정이 나면 같은 작업 안에서 원고에 반영한다.
6. **실험만 진실이다.** 근거 등급은 [문헌] [시뮬] [실험]이다. 시뮬레이션은 가설을 거르고 순서를 정하는 데만 쓴다. 가설 채택과 원고의 결과 문장은 [실험]만 근거가 된다.
7. **측정을 먼저 믿을 수 있게 한다.** 개선을 주장하기 전에 기준선을 재현하고, 보정·반복 수·오차를 기록한다.
8. **논문은 방법과 글쓰기를 함께 배우는 자료다.** 논문 페이지마다 글쓰기 노트를 남긴다.

# 작업 흐름과 폴더

search → 정리·비교 → 큰 그림 → 가설 → 검증 → 원고 → (기각이나 새 공백이 생기면 다시 search)

- `papers/` — 논문 수집과 search 라운드. 작업 전에 `papers/README.md`를 읽고 따른다.
- `wiki/` — 논문 페이지, 개념, 비교표, 공백과 RQ 후보. 작업 전에 `wiki/README.md`를 읽고 따른다.
- `bigpicture.md` — 최종 주장, 가설 지도, 현재 search 범위.
- `hypotheses/` — 가추로 세운 최소 가설과 판정. 작업 전에 `hypotheses/README.md`를 읽고 따른다.
- `experiments/` — 실험·시뮬레이션·기준선 재현 기록. 작업 전에 `experiments/README.md`를 읽고 따른다.
- `manuscript/` — 원고 = 연구 설계도. 작업 전에 `manuscript/README.md`를 읽고 따른다.
- `explainer/` — (선택) 위키를 배경지식으로 대상 논문 설명 페이지를 만든다. 작업 전에 `explainer/README.md`를 읽고 따른다.
- `decision_log.md` — 가설·실험·원고·큰 그림·공백 판정에 관한 결정 기록. 위키 변경 기록은 `wiki/log.md`에 따로 둔다.

# 검증 규칙 (모든 작업에 적용)

- 원문에 적힌 내용과 나의 추론을 구분한다. 추론에는 `[추론]`을 붙인다.
- 판단에는 원문 위치(p. / Fig. / Table) 또는 실험 ID(`E03`)를 함께 적고, 근거 등급([문헌] [시뮬] [실험])을 붙인다.
- 확인하지 못한 내용은 채우지 않고 `needs_review`로 남긴다. 제목·DOI·수치를 지어내지 않는다.
- 원문을 확보하지 못한 논문은 요약하지 않는다.
- 측정 조건이 다른 수치를 같은 조건의 성능처럼 비교하지 않는다.

# 판정이 나면 한 번에 갱신할 것

`experiments/E…/result.md` → `hypotheses/H….md` 상태 → `manuscript/draft.md` 해당 절 → `bigpicture.md` 가설 표 → `decision_log.md`

하나라도 빠지면 작업이 끝나지 않은 것이다.

# 사람이 결정하는 것

- 큰 그림의 변경: 최종 주장, 가설 지도의 구조
- 사전 기각 기준의 잠금, 가설의 채택·기각 확정
- 위키 논문 페이지의 `status: checked`, RQ 채택, 원고 주장 문장의 확정
- 실험 수행(에이전트는 프로토콜 초안, 분석, 기록을 맡는다)

에이전트는 위 항목을 제안까지만 하고, 사람이 확인한 뒤 반영한다. 에이전트가 직접 갱신하는 것은 `bigpicture.md`의 가설 표 상태 열과 "현재 search 범위", 그리고 `decision_log.md`·`wiki/log.md` 기록이다. `bigpicture.md`를 갱신할 때마다 `decision_log.md`에 적는다.
